# Security Policy

## Reporting a Vulnerability

If you find a vulnerability in codemirror-lang-raku, do not open a public issue. Report it through GitHub's [Private vulnerability reporting](https://github.com/kan/codemirror-lang-raku/security/advisories/new) instead. Only the maintainer can see the report until a fix is published.

Please include:

- What the vulnerability is
- Steps to reproduce it (the Raku source that triggers it, if any)
- The expected impact

Reports are checked and answered as soon as possible.

## Scope

In scope are the code in this repository, the [`codemirror-lang-raku`](https://www.npmjs.com/package/codemirror-lang-raku) package on npm, and the [demo](https://kan.github.io/codemirror-lang-raku/). Fixes are released only for the latest version.

Please report these elsewhere:

- Problems in CodeMirror or Lezer themselves: the [CodeMirror](https://github.com/codemirror) project
- Vulnerabilities in other dependencies: the project that publishes the dependency
